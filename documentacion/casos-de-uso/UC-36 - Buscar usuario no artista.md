| **Descripción**  | El caso de uso inicia cuando un usuario desea buscar un usuario no artista en el sistema. |  |
| **Precondición**  | • El usuario debe haber iniciado sesión. |  |
| **Secuencia**  | **Paso**  |  |
| **normal**  | 1  | El usuario selecciona la opción “Buscar un usuario no artista”. |
|  | 2 | El sistema solicita que se seleccione un criterio de búsqueda: Nombre de usuario Correo electrónico Si el usuario es un administrador, el sistema adicionalmente permite estos criterios de búsqueda: Nombre real DNI/CI |
|  | 3 | El usuario selecciona y completa los criterios de búsqueda que desea. |
|  | 4 | El sistema busca y muestra a los usuarios que cumplen los criterios de búsqueda. |
|  | 5 | El usuario selecciona un usuario. |
| **Salida** | El sistema retorna un artista |  |
