| UC–20  | Buscar solicitud de servicio |  |
| :---- | :---- | :---- |
| **Objetivos**  **asociados**  | OBJ–02 Formalizar el seguimiento de arte a medida |  |
| **Requisitos**  **asociados**  | • IRQ–01 Información sobre artistas • IRQ–02 Información sobre clientes • IRQ–11 Información sobre solicitudes de servicio. |  |
| **Descripción**  | El caso de uso inicia cuando un usuario desea buscar una solicitud de servicio de un cliente a un artista. |  |
| **Precondición**  | • El usuario inició sesión en el sistema. • La solicitud de pedido que el usuario desea buscar existe en el sistema. |  |
| **Secuencia**  | **Paso**  |  |
| **normal**  | 1  | El usuario selecciona la opción “Buscar una solicitud de servicio”. |
|  | 2 | El sistema solicita que se seleccionen y completen los datos de filtrado deseados: Artista Cliente Nombre del servicio Tipo Si es un servicio de carácter adulto o sensible Fecha de solicitud |
|  | 3 | El usuario selecciona y completa los datos de filtrado que desea. |
|  | 4 | El sistema busca y muestra las solicitudes de servicio que cumplen los criterios de búsqueda.  |
|  | 5 | El usuario selecciona una solicitud de servicio. |
| **Salida** | El sistema retorna una solicitud de servicio. |  |
