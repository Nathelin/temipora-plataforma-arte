| UC–52  | Buscar reseña |  |
| :---- | :---- | :---- |
| **Objetivos**  **asociados**  | • OBJ–01 Facilitar la conexión entre productores y consumidores • OBJ–02 Formalizar el seguimiento de arte a medida • OBJ–03 Mejorar la protección de productores y consumidores |  |
| **Requisitos**  **asociados**  | • IRQ–01 Información sobre artistas • IRQ–02 Información sobre clientes • IRQ-04 Información sobre productos • IRQ-05 Información sobre servicios • IRQ-06 Información sobre pedidos • IRQ-07 Información sobre ventas • IRQ-14 Información sobre reseñas |  |
| **Descripción**  | El caso de uso inicia cuando un usuario desea buscar una reseña registrada en el sistema. |  |
| **Precondición**  | • El usuario debe haber iniciado sesión. • Debe existir la reseña que el usuario desea buscar. |  |
| **Secuencia**  | **Paso**  | **Acción**  |
| **normal**  | 1  | El usuario selecciona la opción “Buscar una reseña” |
|  | 2 | El sistema solicita que se seleccionen y completen los datos de filtrado deseados: Producto o servicio asociado Artista asociado Cliente asociado Fecha de reseña |
|  | 3 | El usuario selecciona y completa los datos de filtrado que desea. |
|  | 4 | El sistema busca y muestra las reseñas que cumplen los criterios de búsqueda.  |
|  | 5 | El usuario selecciona una reseña. |
| **Salida** | El sistema retorna una reseña |  |
