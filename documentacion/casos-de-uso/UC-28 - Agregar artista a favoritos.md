| UC–28  | Agregar artista a favoritos |  |
| :---- | :---- | :---- |
| **Objetivos**  **asociados**  | • OBJ–01 Facilitar la conexión entre productores y consumidores |  |
| **Requisitos**  **asociados**  | • IRQ–01 Información sobre artistas • IRQ–08 Información sobre listas de favoritos. |  |
| **Descripción**  | El caso de uso inicia cuando un cliente desea añadir a un artista a su lista de artistas favoritos para tener acceso rápido a su perfil. Esta información también será utilizada al ofrecer descuentos por inactividad a los usuarios. |  |
| **Precondición**  | • El usuario inició sesión en el sistema. • El artista que desea añadir a su lista de favoritos existe en el sistema. |  |
| **Secuencia**  | **Paso**  |  |
| **normal**  | 1  | El usuario solicita añadir a un artista a su lista de favoritos. |
|  | 2 | El sistema solicita que indique qué artista. |
|  | 3 | El usuario selecciona un artista (Ver UC-23 “Buscar artista”) |
|  | 4 | El sistema despliega la información pública del artista. |
|  | 5 | El usuario solicita agregarlo a su lista de favoritos. |
|  | 6 | El sistema agrega al artista a la lista de favoritos del usuario. |
| **Postcondición**  | Se asoció a un artista a la lista de favoritos de un usuario. |  |
| **Excepciones**  | **Paso**  |  |
|  |  |  |
|  |  |  |
|  |  |  |
| **Rendimiento**  | **Paso**  |  |
|  | 4  | 1 segundo. |
|  | 6 | 1 segundo. |
| **Frecuencia**  | 1 vez/mes  |  |
| **Estabilidad**  | alta  |  |
