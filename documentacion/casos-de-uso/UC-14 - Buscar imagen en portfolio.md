| **normal**  | 1  | El usuario selecciona la opción “Buscar una imagen en portfolio”. |
|  | 2 | El sistema solicita que se seleccionen y completen los datos de filtrado deseados: Artista Título Medio (tradicional/digital) Si presenta o no contenido sensible |
|  | 3 | El usuario selecciona y completa los datos de filtrado que desea. |
|  | 4 | El sistema busca y muestra las imágenes que cumplen los criterios de búsqueda. |
|  | 5 | El usuario selecciona una imagen. |
| **Salida** | El sistema retorna una imagen. |  |
