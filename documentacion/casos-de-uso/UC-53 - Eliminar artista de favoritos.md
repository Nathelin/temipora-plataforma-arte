| UC–53  | Eliminar artista de favoritos |  |
| :---- | :---- | :---- |
| **Objetivos**  **asociados**  | • OBJ–01 Facilitar la conexión entre productores y consumidores |  |
| **Requisitos**  **asociados**  | • IRQ–01 Información sobre artistas • IRQ–08 Información sobre listas de favoritos. |  |
| **Descripción**  | El caso de uso inicia cuando un usuario desea eliminar un artista de su lista de favoritos. |  |
| **Precondición**  | • El cliente debe haber iniciado sesión. • El artista que desea eliminar de su lista de favoritos existe en el sistema y en su lista. |  |
| **Secuencia**  | **Paso**  |  |
| **normal**  | 1  | El usuario solicita eliminar a un artista de su lista de favoritos |
|  | 2 | El sistema solicita que indique qué artista. |
|  | 3 | El usuario selecciona un artista de su lista de favoritos (Ver UC-23 “Buscar artista”) |
|  | 4 | El sistema despliega la información pública del artista. |
|  | 5 | El usuario solicita eliminarlo de su lista de favoritos. |
|  | 6 | El sistema desvincula al artista de la lista de favoritos del usuario. |
| **Postcondición** | Se desvinculó a un artista de la lista de favoritos de un usuario. |  |
| **Excepciones**  | **Paso**  |  |
|  |  |  |
|  |  |  |
|  |  |  |
| **Rendimiento**  | **Paso**  |  |
|  | 7  |  |
| **Frecuencia**  | 5 veces al día |  |
| **Estabilidad**  | alta  |  |
